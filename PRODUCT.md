# EduTutor Pro — Product Overview

## Mission
EduTutor Pro is a premier SaaS marketplace and education management platform connecting students/parents with verified home tutors and online educators across major cities. It provides end-to-end tuition discovery, algorithmic matching, demo class scheduling, student attendance/progress reporting, credit wallet purchasing, and custom administrative governance.

## User Personas
1. **Parents / Students**:
   - Post customized tuition requirements (subjects, curriculum, class grade, mode, schedule, budget).
   - Discover verified tutors, compare educator profiles side-by-side, schedule trial demo classes, and track ongoing tuition milestones.
2. **Tutors / Educators**:
   - Build a verified professional profile with verified qualifications, subject listings, and hourly/monthly rates.
   - Monitor the Smart Lead Radar for real-time matches in their locality.
   - Manage the student acquisition pipeline using the interactive Kanban board (Applied -> Demo Scheduled -> Demo Completed -> Enrolled).
   - Unlock parent contact details with Contact Credits and manage wallets/subscriptions.
3. **Administrators & Operations**:
   - Executive dashboard with business intelligence charts, real-time platform statistics, and dispute resolutions.
   - Manage tutor background verifications, parent enquiries, commissions ledger, and dynamic platform theme branding.

## Surfaces & Modes
- **Public & Discovery** (`Persuade` / `Read`): Home landing page, tutor search directory, tuition leads board, pricing, how it works, about, and terms.
- **Tutor Portal** (`Operate`): Tutor command center, leads management, demo pipeline, availability scheduler, wallet & billing.
- **Parent Portal** (`Operate`): Requirements manager, tutor matches, demo class scheduler, ongoing tuitions & progress reports.
- **Admin Portal** (`Operate`): Analytics dashboard, verification queues, commission settlement engine, audit trail.
